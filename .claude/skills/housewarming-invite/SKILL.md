# 집들이 초대장 만들기

민주 & 찬호의 첫 집들이 초대장(https://doomoolhead.github.io/Invitations/)과 **같은 구조와 디자인**으로 새 초대장을 만든다.
틀은 `template/`에 있고, 입력값을 `invite.json`으로 정리해 `scripts/build.py`를 돌리면 사이트 폴더가 나온다.

## 고정 / 입력 구분

| 영역 | 처리 |
|---|---|
| 맨 위 초대장 제목 (`title`) | **입력받기**. 예: "밍짜네 집들이 초대장" |
| 제목 아래 초대 문구 (`subtitle_html`) | **입력받기**. `<em>강조</em>`(빨간 글씨), `<br>`(줄바꿈) 사용 가능 |
| 세 가지 약속 (`promises` 3개) | 각각 **제목·부제목·사진 입력받기**. 섹션 이름(`promises_label`)은 기본 "짜릿한 추억을 위한 세 가지 약속" |
| 약속 사진 | 한 줄에 높이를 맞춰 나란히 배치(자동). 누르면 확대·좌우 넘김. 얼굴·노출 부위는 모자이크 |
| 초대말 (`letter_lines`) | **기본 문구 고정**. 사용자가 바꾸고 싶다고 하면 줄 단위로 입력받아 교체 |
| 서명 (`sign`) | 기본 `- 민주&찬호 -` |
| 언제 올래? 올 수는 있니? (`dates`) | **후보 날짜를 입력받아 초기값으로 반영**. 이후엔 호스트 모드에서 추가·수정·삭제(시트에 저장) |
| 오시는 길 | **고정**: 동탄2신도시호반베르디움22단지 2202동 404호, 주차 안내, 대중교통(M4137·6002 노선 링크, GTX·SRT 동탄역 픽업) |
| 참석 폼·투표 현황·참석자 카드·호스트 모드 | 고정 (form.js / rsvp.js) |

## 진행 순서

1. **물어보기** (한 번에 묶어서, 모르는 것만):
   - 초대장 제목, 제목 아래 초대 문구(강조할 부분)
   - 세 가지 약속: 각 제목 / 부제목 / 사진(없어도 됨)
   - 후보 날짜들
   - 초대말을 바꿀지 (기본 문구를 보여주고 확인)
   - 배포 위치: 같은 `Invitations` 저장소의 하위 폴더(예: `/2028-spring/`)로 할지, 루트를 교체할지. **기존 초대장 링크를 이미 보냈다면 루트를 덮어쓰지 말고 하위 폴더로**.
   - 호스트 비밀번호(삭제·날짜 관리용). 사용자에게 묻고, `invite.json`은 빌드용 임시 파일로만 쓰고 저장소에 올리지 않는다.
   - 응답 저장용 구글 시트: 초대장마다 **새 시트 + 새 Apps Script 배포**를 권장(이전 집들이 응답과 섞이지 않게).
2. **사진 처리**: 받은 사진을 작업 폴더에 복사하고, 얼굴은 보고 직접 모자이크 영역을 정한다.
   - 좌표는 사진 크기 대비 비율 `[x0, y0, x1, y1]` (0~1).
   - 세기: `light`(아는 사람은 알아봄) / `medium` / `strong`(기본) / `heavy`(노출 부위 등 완전히 가림).
   - 공개 링크라서 **노출 부위는 항상 heavy로 가린다**. 사용자가 "누군지 알아볼 정도로"라고 하면 얼굴은 light.
   - 결과를 잘라서 직접 확인한 뒤 진행한다.
   - 한 장이 유난히 세로로 길어 줄이 높아지면 `"ratio": 0.75, "position": "50% 60%"`로 맞춘다.
3. **invite.json 작성** — `examples/mingjja.json` 형식 그대로. 썸네일(`og_image`)은 주인공이 가운데 오게 `center_x`, `top_y`, `width`(0~1)로 지정.
4. **빌드**: `python3 scripts/build.py invite.json OUT_DIR`
   - `OUT_DIR`: 배포할 사이트 파일
   - `OUT_DIR.apps-script.gs`: 호스트 비밀번호가 들어간 Apps Script 코드. **공개 저장소에 절대 올리지 말고** 사용자에게 파일로 보낸다.
5. **확인**: Playwright로 390px 폰 화면 캡처, 콘솔 에러 없음, 가로 스크롤 없음 확인.
6. **구글 시트 연결 안내** (사용자가 직접):
   1. sheets.new → 확장 프로그램 → Apps Script → 코드 통째로 붙여넣기 → 저장
   2. 배포 → 새 배포 → 웹 앱 / 실행: 나 / 액세스: **모든 사용자** → 권한 허용(고급 → 이동)
   3. 받은 `…/exec` 주소를 `invite.json`의 `endpoint`에 넣고 다시 빌드
   - 코드만 고칠 땐 "새 배포"가 아니라 **배포 관리 → 수정 → 새 버전** (주소 유지).
7. **배포**: `DooMoolHead/Invitations`의 `main`에 커밋·푸시(Pages 자동 배포, 1~2분). 링크와 썸네일을 사용자에게 전달.
   - 폰에 예전 화면이 남아 있으면 링크 끝에 `?2`를 붙여 열어보라고 안내.
   - 이 클라우드 환경은 github.io·script.google.com 접속이 막혀 있을 수 있음 → 실제 동작은 사용자에게 폰으로 확인 요청. 로컬 검증은 Apps Script를 가짜 시트에 붙여 돌리는 방식으로 한다(Node `vm`에 SpreadsheetApp·ContentService·LockService·PropertiesService 스텁).

## 디자인 규칙 (사용자가 이전에 요청한 것들)

- "No!"와 제목은 글자 **밑선을 맞춘다**(No!에 `top:3px` 보정), No!와 제목 사이 간격은 좁게(첫 칸 56px).
- 부제목은 제목 **바로 아래** 붙인다.
- 편지 글씨는 **줄 위에 올라앉게**(줄 간격 36px, padding-top 9px). 서명도 한 줄을 차지.
- 사진 밑에 캡션 문구는 넣지 않는다. 흰 틀은 사진에 딱 맞게(사방 6px).
- 버튼: 누르기 전 "등록", 누른 뒤 "등록완료!".
- 정류장 밑줄은 파란색.
- 수정 요청은 claude.ai 아티팩트 댓글로 받는 방식이 잘 맞았다: 미리보기 아티팩트를 올리고 댓글마다 고친 뒤 스레드에 답한다.

## 파일

- `template/index.html` — 페이지 틀. `{{TITLE}}` `{{SUBTITLE_HTML}}` `{{PROMISES_LABEL}}` `{{PROMISES_HTML}}` `{{LETTER_HTML}}` `{{OG_DESC}}` `{{SITE_URL}}` `{{YEAR}}` `{{VERSION}}`
- `template/config.js` — 오시는 길(고정)·호스트·날짜·연결 주소
- `template/rsvp.js` `form.js` `lightbox.js` — 데이터·폼·확대보기 (수정 불필요)
- `template/apps-script.gs` — 구글 시트 백엔드(비밀번호 자리 `'여기에-비밀번호'`)
- `scripts/build.py` — 빌더 (Pillow 필요)
- `examples/mingjja.json` — 첫 집들이 초대장 입력값
